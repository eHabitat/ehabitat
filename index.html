eHabitat for Energy Efficiency & CO2 Reduction

eHabitat provides synchronized electrical consumption and weather data to power Non-Intrusive Load Monitoring (NILM) models, helping users understand and optimize their energy consumption.

🔗 Start 
# Install the library
pip install ehabitat

# Import and load dataset
from ehabitat import load_nilm_dataset

# Load NILM dataset with weather data
dataset = load_nilm_dataset("eHabitat")

# Access energy and weather dataframes
energy_df = dataset.get_energy_data()
weather_df = dataset.get_weather_data()

print(f"Energy records: {len(energy_df)}")
print(f"Weather variables: {list(weather_df.columns)}")

eHabitat-NILM Dataset

High-frequency aggregate energy consumption data synchronized with detailed weather parameters (temperature, humidity, solar radiation). Essential for developing robust NILM models that account for environmental factors.

Weather-Synchronized High-Frequency

eHabitat-1k

A carefully selected and validated subset of 1,000 energy events and consumption profiles. Ideal for standardizing performance testing and rapid prototyping of energy disaggregation algorithms.

Benchmark Standard 1000 Events

eHabitat-Interactive

Future extension enabling proactive energy management. Data supports research into robot actions (e.g., turning off unused appliances, adjusting thermostats) based on NILM predictions.
